# Flight guide

The native Decentraland guide opens on scene entry. Five illustrated lessons cover the central updraft, native steering/gliding, the ten-orb return, temporary leaves and airtime scoring. Players can move back, jump between steps using the progress track, skip, or finish. The FLIGHT GUIDE image button at the bottom of the right-side score menu reopens it from the live HUD. On desktop, press Escape to free the cursor before using the guide.

The guide shares the existing React ECS renderer; it never replaces native movement or changes score/physics. Gameplay continues behind it. Guide progress lasts for this scene session. The interface has no FX or Motion buttons. Click audio and hover/press animations stay active.

## Artwork and sound

`src/tutorial.tsx` contains lesson content, layout and interaction state. `scripts/generate-tutorial-assets.cjs` generates editable SVG masters and PNG game textures in `assets/ui/tutorial`, plus the original 85 ms `assets/sounds/ui-click.wav`. The SVGs use blue/teal wind, emerald leaves, gold orbs, bevelled buttons and fine gold frames. The existing Endless Vortex logo is enlarged and centered, with 30% of its image height above the frame. Layout reserves screen-safe headroom for this overhang. Skip sits in the footer between Back and Next. The frame glow is clipped to the chamfered silhouette, preserving transparent corners. Descriptions use 16–20 px type, titles use 20–28 px type, and gold goal text uses 22–36 px type in a dedicated callout. Goals remain visible on every supported layout, with a separate column on short landscape screens. Texture exports avoid relying on SVG support in the native client. SVG source masters are excluded from deployment. NEXT, SKIP, BACK and FLY use bold, filled Roman glyph paths with gold bevels, dark outlines and cyan accents matching the game logo exported as transparent light/dark PNG wordmarks; native UI text is removed from these controls. Filled ivory/gold lettering is shown at rest. A single image switches to a light blue version with a deep blue outline over the gold hover background, avoiding overlapping light/dark image layers. Lettering is capped at 72% of button width and approximately 62% of button height, leaving clear padding. All three navigation controls use the same image treatment. Their generator has no system-font dependency.

Regenerate with `npm run tutorial:assets` after editing the generator. `@resvg/resvg-js` is a development dependency; it is not loaded by the game.

## Preview and verification

Run `npm run tutorial:preview` and open http://127.0.0.1:8128. This interactive browser fixture renders the actual tutorial JSX and plays the generated WAV. It is a layout/interaction preview, not the Decentraland client. Open http://127.0.0.1:8128/hud for the interactive score HUD fixture, including the footer button that opens this guide. For the game preview, use `npm start`.

Automated coverage checks navigation, completion, skip/replay, click callbacks, image-only button labels, light/dark hover states, larger text, goal visibility, centered logo overhang and safe headroom, transparent corner cutouts, stable hover hit areas, native HUD integration, texture existence, safe-area positioning, 44 px controls and non-overlapping footer controls across desktop, tablet and both phone orientations, including 320 × 568 and 568 × 320. The guide applies `UiCanvasInformation` dimensions and insets, matching the existing HUD. Short viewports show the description and emphasized goal without optional control hints or illustrations.

Before release, verify in supported Decentraland desktop and mobile clients: cursor unlock, touch activation, sound playback, notch insets, orientation changes and interaction with native Explorer overlays. Browser fixtures and ECS tests do not prove native device compatibility.

## Shared score HUD

`src/airtime-ui.tsx` reuses the tutorial’s clipped teal/gold frame and engraved image lettering. AIRTIME, MEDALS and NEARBY label sections in a single side menu; FLIGHT GUIDE is its final control, followed by an enlarged, centered Endless Vortex logo in the footer. Exactly 30% of the logo height projects below the panel. The footer preserves the logo aspect ratio and reserves on-screen space for the full image before calculating visible nearby rows. A separate top-center ORBS card uses a full ORBS gold wordmark, smaller gold sprite digits below it, and ten larger, closely spaced orb icons that light up as pickups accumulate. Wide cards use one row of ten; narrow cards use two rows of five. The guide button retains the gold default / yellow hover with light-blue lettering behavior, click sound and press animation.

Layout derives from canvas dimensions and safe insets. Portrait menus sit below the orb card to prevent overlap. Short screens limit nearby rows, retaining the local player whenever a row fits. Rows use visible indices for layout, so gaps in rank cannot push content outside the frame. Live scores, best time, danger vignette and rank achievements remain active. Each new 100-second rank shows its insignia with a matching miniature-orb splash and achievement audio. Header glyph masters and both gold/light-blue variants are generated by `npm run tutorial:assets`, alongside `hud-panel` and `hud-orbs` frame textures.

### Blue airtime treatment

AIRTIME has a dedicated light-blue crest with wing tips, a vortex seal and fine gold trim. `digits-blue.svg/png` supplies fourteen glyph cells (0–9, decimal point, colon, slash and seconds suffix) in a six-column, three-row atlas. The main timer renders minutes:seconds.hundredths and nearby scores render minutes:seconds; the underlying airtime and ranking values remain seconds. The HUD atlas does not replace the world avatar-badge assets.

The medal section and its 15/30/60-second milestones have been removed. Nearby rows are taller, with a framed, bilinear native `avatarTexture` bound to each row's own user ID and a larger blue score on its own line. The browser fixture uses placeholder portraits; the Decentraland client resolves the actual player images.

Flight Guide’s background and lettering render at 50% of their previous width and height, centered in the existing 44 px high pointer target. Hover, sound, and opening the guide still use the full target. Layout shows fewer rows where needed to keep the larger emblems and scores inside the available safe area.

The landscape side menu starts below the Local Tools area (56 px from the safe top on taller screens, 44 px on short screens). Taller layouts add vertical spacing between sections. Nearby players follow the timer and best score directly, with no medal section.

The gold orb-count atlas shares the blue digit shapes, with a cream/yellow/amber palette. Achievement popups contain only the earned rank insignia and small palette-matched orb sprites, with no frame, description or seconds caption.

AIRTIME and ORBS use distinct game-logo artwork generated by `scripts/logo-headings.cjs`: filled serif outlines, enlarged end letters, metallic blue/gold faces, layered gradient borders, cyan glow, and no orb or vortex ornaments. Both titles are enlarged, horizontally centered, and positioned with exactly 30% of their image height above their panel top. Layout reserves safe-area headroom for the overhang and keeps the count beneath ORBS. `scripts/logo-letterforms.json` stores the vector contours so regeneration is independent of installed fonts. The native HUD uses transparent PNG exports; the editable SVG masters remain alongside them. BEST time uses the same blue digit atlas as the main clock, including separators.

The landscape altitude meter is a slim horizontal card anchored to the lower-right safe area, to the right of the native chat area. It uses a wide teal/gold chamfered frame, an enlarged ALTITUDE blue metallic wordmark with a 20% top overhang beside blue digit sprites for meters, and a 16 px bar beneath them. Sidebar row/footer sizing reserves clearance above this meter on short landscape screens. Its thicker bar uses generated `altitude-track` and `altitude-fill` textures; fill width follows the existing altitude percentage, clamped to 0–100 with invalid values empty. The blue/cyan gradient and glass highlight are part of the SVG masters.

The top lesson/step description uses restrained yellow Avenir Next Demi Bold vector outlines, left aligned with the progress track and formatted as `FLIGHT GUIDE · 01 OF 05 · THE UPDRAFT`, rasterized as a single image per lesson (including its count and separators). A smaller, muted-gold FLIGHT GUIDE label establishes hierarchy. Wide, short-landscape and stacked phone variants keep it readable without native numeric font artifacts. `scripts/tutorial-step-headings.cjs` and stored `step-letterforms.json` contours regenerate these assets without system-font dependencies. Compact phones use the short lesson description to preserve footer clearance.

Nearby usernames now carry original winged flight-rank insignia, replacing the plain ordinal label. These use a dedicated 88×44 px emblem column on desktop, roughly twice the initial badge size. Narrow panels stack a 96×48 px emblem beneath the username and above the blue score, with taller rows so all elements remain separate. A shared `src/flight-ranks.ts` selector preserves the existing run thresholds: Cadet at 0, then Scout, Pilot, Ace, Sky Captain, Storm Rider, Sky Marshal, Vortex Guard, Aether Commander, Celestial and Vortex Legend at each 100-second boundary through 1,000. Metals, feather layers, chevrons, vortex gems, crowns and stars distinguish progression. Nearby remote ranks use the existing approximate remote run time; these are run ranks, not permanent account unlocks. Overhead avatar badges use matching insignia plates with a separate score ribbon and explicit alpha masks. The former medal and numeric milestone popups are replaced by a single rank achievement effect. Each tier sounds once per flight; Vortex Legend never repeats above the cap. The two-second popup fades in and out, defers while the reward camera is active and is dismissed by the final score. Regenerate with `npm run rank:assets`; see `docs/previews/rank-insignia.png` for the full progression.

World update: arena dimensions and scene geometry fit an 80 m / 5×5 layout, and the orb recovery height is now fifty meters. The overhead rank badge factory is no longer called by the scene; Nearby rank icons remain in the HUD. `src/arena-enclosure.ts` creates 64 static physics-only walls around the arena at a 29.16 m inner radius, starting 1.5 m above the floor and ending at 83.21875 m, with no graphics, solid center, or roof. Leaf glow is baked into the authored material by `scripts/package-leaf-model.cjs`.
